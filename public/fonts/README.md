# Gilroy Font Files

Place your Gilroy font files here. Required files:

- Gilroy-Regular.woff2
- Gilroy-SemiBold.woff2
- Gilroy-Bold.woff2
- Gilroy-ExtraBold.woff2

Gilroy is a commercial typeface by Radomir Tinkov, available at:
https://www.myfonts.com/fonts/radomir-tinkov/gilroy/

The app falls back to Nunito → Inter → sans-serif if Gilroy files are absent.
